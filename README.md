# ArabicBookings
برنامج Windows للعيادات والصوالين ومراكز التجميل: جدول مواعيد ذكي بعمود ملون لكل طبيب أو موظفة، والحجز بنقرة مع منع تعارض تلقائي. تذكير واتساب جاهز لكل موعد بضغطة، وباقات جلسات مسبقة تُخصم عند الحضور تلقائيًا، وإيصالات PDF باسم منشأتك، وتقارير الإيراد والغياب والإشغال. التواريخ هجري وميلادي معًا، وكل بيانات عملائك على جهازك — دون إنترنت ودون اشتراك شهري.
